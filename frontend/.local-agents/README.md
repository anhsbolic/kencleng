## Policy

- New frontend development runs create fresh task directories under `works/`.
- Generated Exploration, Techplan, Build/Patch, Code Review, Testing, and PR artifacts are task evidence/history, not project-wide authority by themselves.
- Reusable truth learned during a run must be promoted into the project document/spec/architecture source that owns that concern.
- Old frontend-generation work directories were removed from the active tree during the 2026-09 frontend reboot so new agents do not treat retired implementation decisions as current context.
- Git history remains the archive for those removed artifacts.
- Do not copy old work artifacts forward merely to seed a new run.

The frontend reboot preparation is governed by `../../docs/project/frontend-reboot-plan.md`.
