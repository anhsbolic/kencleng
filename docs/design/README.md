# Product Design Standards

These standards preserve approved reusable design direction. They do not select features, routes, release scope, or delivery order.

| Concern | Authority |
| --- | --- |
| Product meaning and business commitments | [Product intent](../product/product-intent.md) |
| Product-design judgment | [Product design principles](product-design-principles.md) |
| Brand and Product UI direction | [Brand/Product UI brief](brand-product-ui-brief.md) |
| Visual-system guidance | [Design guidelines](design-guidelines.md) |
| Reusable interaction behavior | [Patterns](patterns.md) |
| Asset selection and governance | [Asset governance](asset-governance.md) |
| Direction-level visual evidence, not production specifications | [Selected-direction visual references](visual-references/selected-direction/README.md) |

Product truth is not established by illustrative design examples. Future delivery specifications and API contracts may implement approved product decisions but do not replace product authority.
