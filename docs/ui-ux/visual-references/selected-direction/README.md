# Selected Direction Visual References

> Status: Approved direction references
> Selected direction: **Sunlit Editorial**
> Core thesis: **Evidence-Led Optimism**

This directory contains the human-approved visual proof used to validate the selected Kencleng brand/Product UI direction across public and authenticated surfaces.

## Authority

These images are evidence for:

- overall visual character;
- public vs authenticated expressive intensity;
- editorial composition principles;
- trust/information hierarchy;
- restrained editorial-yellow usage;
- relationship between real imagery, typography, and structured progress;
- the Evidence Journal concept.

They are **not** authority for:

- business/domain behavior;
- API shape;
- exact route structure;
- component decomposition;
- CSS/Tailwind strategy;
- exact spacing values;
- exact color values;
- exact fonts;
- exact responsive breakpoints;
- pixel-perfect production reproduction.

If a visual detail conflicts with product/domain truth, product/domain truth wins.

## Interpretation Rule

Use these references to preserve **design relationships and character**, not screenshot geometry.

A healthy translation asks:

- Is the information hierarchy equivalent in intent?
- Does the interface feel like one Sunlit Editorial system?
- Is optimism supported by evidence rather than decoration?
- Are fact, report, status, and uncertainty legible?
- Does public expression become appropriately calmer in product UI?
- Would realistic content still work?

Do not reproduce an illustrative label, number, campaign, organization, or state from these references unless canonical product/API data supports it.
