## Decisions still open

- The next bounded Product outcome, delivery scope and sequencing are **not selected**.
- Detailed eligibility, permissions, financial/privacy requirements, acceptance criteria and feature workflows need their own decisions when material.
- UX owns actor inquiry, flow and navigation; UI owns visual expression; Engineering owns technical mechanisms and independently required safeguards.
- A Product proposal, Design prototype or repository scaffold is not permission to implement, transact, deploy or claim real-world evidence.

Begin with [Product Intent](product-intent.md), then inspect relevant evidence and make only decisions needed for the next authorized scope. [Design](../design/README.md) and [Engineering Standards](../engineering/standards/README.md) retain separate authority.
