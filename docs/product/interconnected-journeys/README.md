## Why this exists

The representative R1–R4 scenarios are a useful helicopter view, but labels such as “legitimate Organization context” are too broad to select an initial bounded piece of real work. This checkpoint captures the **connected road network** beneath those scenarios so a later discussion can assess where to begin without silently losing actor value, authority, prerequisites, negative paths or changes over time.

The research map has **two resolutions**, not two mandatory procedural phases:

1. **Level 1 — Journey Landscape:** R1 Organization representation/review, R2 Campaign proposition/curation/publication/eligibility, R3 Public Visitor consideration/contribution/Donatur, R4 Campaign lifecycle/continuing accountability; X1 Platform Operator is an exceptional cross-cutting boundary.
2. **Level 2 — Interconnected Meaningful Transitions:** 26 provisional product/experience consequence nodes across R1–R4; typed cross-journey dependencies, conditional feedback/re-entry, negative and uncertain outcomes, and visible Product decisions that remain OPEN.

Nodes express changes with real meaning to a human actor or legitimate product state. They are **not** screens, CRUD tasks, API calls, required implementation modules, universal workflow states, or automatically selectable delivery units.
