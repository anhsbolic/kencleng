4: 
5: SQL injection can occur when:
6: 
7: 1. The non-default simple protocol is used.
8: 2. A dollar quoted string literal is used in the SQL query.
9: 3. That query contains text that would be would be interpreted outside as a placeholder outside of a string literal.
