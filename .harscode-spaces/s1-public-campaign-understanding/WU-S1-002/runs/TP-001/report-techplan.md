## What & why

Work Unit ini merencanakan reconciliation kontrak public Campaign untuk Slice 1 agar pengunjung dapat memahami Campaign yang eligible tanpa mewarisi data internal, mengonfirmasi keberadaan Campaign non-public, atau menerima URL media yang tetap dapat diakses setelah penarikan. Hasil yang dituju adalah `CONTRACT_READY`: spesifikasi, threat model, OpenAPI, generated frontend types, dan catatan delivery memiliki satu batas public yang konsisten sebelum implementation backend/frontend dimulai.

## Scope

**Included**

- Menetapkan `GET /campaigns/{campaignId}` sebagai public-only detail projection dengan perilaku `404` yang tidak membedakan resource tidak ada dan non-public.
- Menetapkan public lifecycle, funding decimal-string, organizer provenance plain-text, media states, dan donation action yang jujur untuk Slice 1.
- Menetapkan controlled Campaign-media byte delivery, private storage expectation, dan `Cache-Control: private, no-store`.
- Mereconcile Campaign delivery records, invariant, threat model, split OpenAPI/bundle, generated TypeScript type, integration map, dan tracker yang terkait.
- Mengunci exact public allowlist secara executable: setiap object exact-projection memakai `additionalProperties: false` dan diverifikasi pada dereferenced bundle/generated correspondence.

**Explicitly not included this round**

- Runtime backend/frontend implementation, migrations, route wiring, storage/topology configuration, maupun runtime tests.
- Donation Flow, public listing/discovery, upload/self-service/curation/scheduler, full Organization profile, serta closure/result continuity Slice 3.
- Perubahan Product/MVP atau Product Design authority, repository-wide OpenAPI warning cleanup, dan semua protected Tier-0 implementation paths.

## Architecture / Plan

Plan bergerak linear dari authority delivery ke contract: reconcile Campaign spec/invariant/threat model, sempitkan architecture wording, edit split OpenAPI, validasi dan regenerate bundle/types, lalu reconcile integration map dan tracker setelah evidence lolos. Public detail memuat steward yang sempit serta metadata media; byte media melalui endpoint terkendali yang mengecek ulang eligibility parent dan membership media pada setiap origin request.

**Components touched**

| Component | Purpose / change |
|---|---|
| Campaign delivery specs, invariant, dan threat model | Menjadi authority Slice-1 untuk projection, anti-enumeration, provenance, revocation, dan dependency failure. |

**Not touched / blast-radius boundary:** Tidak ada production code backend atau frontend, migration, private-bucket/topology implementation, maupun perubahan ke Product/Design authority dalam Work Unit ini.

## Interface Contract

| Concern | Contract |
|---|---|
| Public Campaign detail | `GET /campaigns/{campaignId}` dengan `operationId: getPublicCampaignDetail` |
| Media byte delivery | `GET /campaigns/{campaignId}/media/{mediaId}/content` dengan `operationId: getPublicCampaignMediaContent` |
| Authentication / authority | Kedua public operation memakai `security: []`; optional `Authorization` tidak boleh mengubah visibility atau payload. Backend tetap memiliki authority atas eligibility, mapping, funding truth, dan media membership. |
| Trigger / caller | Public visitor atau frontend Slice 1 membaca detail Campaign; `content_url` dipakai sebagai opaque same-origin URL. |

**Response / output**

| Output | Meaning |
|---|---|
| `PublicCampaignDetail` | Exact closed projection: identity, title, purpose/story organizer plain-text, steward, public lifecycle, funding, media, dan unavailable donation action. |
| `PublicCampaignMedia` | Tagged `available`, `absent`, atau `unavailable` state; hanya item metadata yang public-safe. |
| Media content `200` | JPEG/PNG bytes dari controlled path, bukan object-storage URL atau redirect. |

**Error behavior:** Campaign absent, malformed/non-resolvable, atau non-public serta media absent/non-member semuanya memakai `PublicCampaignNotFound` (`404`) yang sama. Dependency failure untuk Campaign eligible atau media bytes memakai `PublicCampaignUnavailable` (`503`). Success dan error touched operations mengirim `Cache-Control: private, no-store`.

## Key decisions

| Decision | Why / consequence |
|---|---|
| Pertahankan satu path detail sebagai public-only composite read (D1). | Menghindari mixed public/privileged payload dan optional-auth/cache leakage tanpa membuat path duplikat. |
| Gunakan standalone projection yang closed-object (D2). | Field internal tidak diwariskan dari `Campaign`/`Organization`; `additionalProperties: false` membuat exact allowlist executable tanpa mengubah field set. |
| Funding memakai tagged availability dan decimal strings (D5). | Zero, unavailable, over-target, serta not-computable tetap bermakna tanpa `float` atau kalkulasi authoritative di frontend. |
| Donation action explicit unavailable (D6). | Slice 1 tetap jujur dan tidak menghasilkan fake Donate control sebelum Slice 2. |
| Media private dengan controlled delivery dan no-store (D7–D8). | Penarikan media menutup origin fetch baru pada URL yang sebelumnya diketahui; tidak ada direct public-bucket/signed URL exposure. |
| Generated types-only artifact (D10). | Kontrak frontend berasal dari aggregate OpenAPI yang digenerate tanpa menambah SDK atau client behavior spekulatif. |

## Material risks / trade-offs

| Risk / trade-off | Exposure / mitigation | Status |
|---|---|---|
| Internal field leakage (RISK-1) | Standalone mapping, closed object schemas, dan downstream forbidden-field regression tests diperlukan. | Mitigated in contract; runtime evidence deferred. |
| Existence disclosure atau auth variance (RISK-2) | Identical `404`, satu public payload, dan auth invariance dikunci; timing parity perlu dibuktikan saat backend implementation. | Mitigated in contract; runtime evidence deferred. |
| Known media URL masih bekerja setelah retraction (RISK-3/RISK-5) | Private storage, controlled recheck, dan `private, no-store`; bytes yang sudah diunduh tidak dapat ditarik kembali. | Mitigated in contract; topology/runtime evidence deferred. |
| Storage outage disajikan sebagai “tidak ada media” (RISK-4) | State `unavailable` dan `503` dibedakan dari `absent`/`404`. | Mitigated in contract. |
| Contract change di atas kertas (Backward Compatibility) | Historical mixed detail/attachment listing berubah, tetapi tidak ada route, generated artifact, atau consumer live yang perlu dimigrasikan. | Accepted for unimplemented boundary. |

## Review & resolution history

Independent Techplan review (`TPR-001`) dijalankan karena plan melintasi spec, OpenAPI, generated frontend contract, dan public/media security boundary. Review menemukan satu Finding blocking: exact allowlist belum tertutup secara executable karena OpenAPI 3.0 default `additionalProperties` permissive. Resolution Run `TPR-RES-001` mengamend R3/R8/R11, Interface Contract, implementation anchors, dan testing checklist untuk mengharuskan `additionalProperties: false` pada setiap exact-projection object serta mengecek dereferenced bundle/generated correspondence. Ini hanya mengeksekusi semantics allowlist yang sudah settled—tidak menambah/menghapus field atau mengubah runtime behavior—sehingga mandatory re-review tidak diperlukan.
