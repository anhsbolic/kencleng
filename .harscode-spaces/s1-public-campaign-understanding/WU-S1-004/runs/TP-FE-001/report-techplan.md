## What & why

Work Unit ini merencanakan detail Campaign publik untuk Slice 1 agar pengunjung dapat memahami tujuan, steward, sumber cerita, lifecycle, funding, media, dan keadaan aksi berikutnya secara jujur. Hasilnya adalah bukti frontend contract-parallel dengan mock pada network boundary; ini memungkinkan klaim `FRONTEND_MOCK_VERIFIED` setelah seluruh bukti dan Human rendered acceptance terpenuhi, tanpa menyatakan integrasi backend nyata sudah terbukti.

## Scope

**Included**

- Route publik App Router `frontend/app/campaigns/[campaignId]/` untuk detail satu Campaign.
- Satu request bertipe `GET /api/campaigns/{campaignId}` yang memakai generated OpenAPI types, TanStack Query untuk server state, dan MSW pada browser/Vitest network boundary yang sama.
- State loading, success, media `available`/`absent`/`unavailable`, funding unavailable, `404` yang public-safe, `503` retryable, dan generic network failure.
- Penyajian funding, provenance, media, dan next action yang jujur; organizer plain text yang aman; aksesibilitas, responsive/rendered evidence, Human rendered acceptance, serta dokumentasi mock browser yang dapat direproduksi.

**Explicitly not included this round**

- Perubahan backend, OpenAPI/generated type, API proxy/rewrite, Caddy/topology, storage, cache, atau enforcement controlled media nyata.
- Donation Flow maupun Donate link/tombol aktif; mutation, polling, optimistic update, perhitungan eligibility, dan Campaign Discovery/Organization detail.
- Fetch Organization tambahan, penggunaan public internal Campaign fields, atau state/lifecycle pasca fundraising yang belum direkonsiliasi.
- Shared design-system/component registry, Zustand store, reusable expressive placeholder asset, serta perubahan root layout/global visual system.
- Klaim `INTEGRATED_VERIFIED`; bukti integrasi nyata tetap menjadi rendezvous WU-S1-003, WU-S1-005, lalu WU-S1-006.

## Architecture / Plan

Route server hanya menyediakan identitas Campaign dari URL. Leaf Client Component yang kecil memiliki lifecycle TanStack Query, lalu memanggil satu fungsi API bertipe. Pada browser mock runtime yang diaktifkan secara eksplisit, MSW mulai sebelum query berjalan dan mengintersepsi HTTP path yang sama; tanpa mock, request yang sama menuju jaringan same-origin nyata saat integrasi tersedia. Tampilan route-local memperoleh seluruh state dari hasil query dan discriminant kontrak, tanpa salinan data pada Zustand, context, atau effect-synchronized state.

**Components touched**

| Component | Purpose / change |
|---|---|
| `frontend/app/campaigns/[campaignId]/` | Route shell, route-local mock bootstrap, query lifecycle, dan detail presentation. |
| `frontend/lib/api/client.ts` dan `frontend/lib/api/public-campaign.ts` | Satu low-level request boundary dan consumer generated `PublicCampaignDetail`. |
| `frontend/lib/hooks/use-public-campaign-detail.ts` | Query key stabil dan hook detail per `campaignId`. |
| `frontend/mocks/` | Fixture contract-faithful serta MSW browser/node handlers untuk detail dan controlled media. |
| `frontend/public/mockServiceWorker.js` | Generated MSW worker untuk browser mock runtime. |
| Tests, `vitest.setup.ts`, dan `frontend/README.md` | Evidence observable melalui node MSW, lifecycle test setup, dan instruksi mock browser. |

**Not touched / blast-radius boundary:** Tidak ada perubahan pada `backend/**`, topology/proxy, `api/openapi/**`, `api/openapi.yaml`, atau `frontend/lib/api/generated/openapi.ts`. `frontend/app/layout.tsx`, `frontend/app/globals.css`, shared component areas, Zustand stores, dan sumber authority product/design/spec juga tetap tidak diubah.

## Interface Contract

| Concern | Contract |
|---|---|
| Endpoint | `GET /api/campaigns/{campaignId}` |
| Authentication / authority | Operasi baca publik; backend secara eksklusif menentukan public eligibility dan makna `404` tetap non-disclosing. |
| Trigger / caller | Route publik `frontend/app/campaigns/[campaignId]/` melalui `getPublicCampaignDetail`. |

**Request / input**

| Field / input | Meaning / requirement |
|---|---|
| `campaignId` | Satu route segment yang di-path-encode oleh request boundary; frontend tidak memvalidasi atau mengklasifikasikan eligibility publik. |

**Response / output**

| Field / output | Meaning |
|---|---|
| `200` | Hanya generated `components["schemas"]["PublicCampaignDetail"]` yang digunakan untuk detail. |
| `404` | Safe not-found/not-public outcome tanpa alasan atau detail diagnostik. |
| `503` | Temporary-unavailable outcome yang dapat di-retry pengguna. |
| Other/network failure | Generic safe failure outcome yang dapat di-retry pengguna. |
| `PublicCampaignMediaItem.content_url` | Referensi opaque yang dimuat native image; MSW hanya mensimulasikan JPEG/PNG pada path controlled yang sama. |

**Error behavior:** Problem Details tidak diparse menjadi copy pengguna; tidak ada `error.message`, stack, header, atau alasan spesifik untuk `404` yang ditampilkan. `404` tidak menyediakan retry, sedangkan `503` dan generic failure memiliki retry eksplisit.

## Key decisions

| Decision | Why / consequence |
|---|---|
| Dynamic route dengan route-local Client query boundary | Identitas tetap bookmarkable, sementara browser server-state terbatas pada boundary terkecil; shell/layout tetap server-capable. |
| Focused typed API function dan centralized low-level helper | Menjaga ownership request/response generated-contract dan satu titik klasifikasi transport tanpa menambahkan semantik auth atau eligibility. |
| MSW hanya pada browser/node network boundary | Browser mock dan test menggunakan HTTP path produksi yang sama; tidak ada mock service branch pada `lib/api/`. |
| Native `<img src={content_url}>` untuk media tersedia | URL controlled yang disuplai kontrak tetap opaque dan tidak menciptakan image optimizer/proxy baru. |
| Query key per `campaignId`, tanpa automatic retry/polling | Tidak ada cache key ad-hoc atau re-request otomatis untuk funding/status; retry hanya melalui tindakan pengguna pada state retryable. |
| Decimal/progress dari API sebagai display input | Tidak ada float conversion, perhitungan ulang, capping, atau eligibility inference di frontend. |
| Missing-media treatment route-local dan struktural | Tidak menciptakan asset ekspresif/reusable sebelum Human Design decision tersedia. |
| Tidak ada committed Playwright regression awal | RTL + node MSW melindungi perilaku kontrak; rendered inspection dan Human acceptance tetap wajib untuk penilaian spasial/produk. |

## Material risks / trade-offs

| Risk / trade-off | Exposure / mitigation | Status |
|---|---|---|
| Public data atau alasan unavailable bocor | Konsumsi dibatasi pada `PublicCampaignDetail`; satu `404` aman dan copy failure tetap; raw error tidak dirender. | mitigated |
| Funding/media dipalsukan atau maknanya runtuh | Decimal hanya ditampilkan, media memakai discriminant dan `content_url` tersuplai; fixture/test mencakup zero, above-target, unavailable, dan absent. | mitigated |
| Organizer text menjadi markup/XSS atau provenance tampak diverifikasi platform | Render sebagai React plain text dan tampilkan attribution organizer; hostile-looking text diuji. | mitigated |
| Mock dapat disalahartikan sebagai integrasi nyata | Evidence menyatakan batas mock; backend projection, controlled delivery, proxy, storage/retraction, cache, dan timing parity tetap deferred. | open |
| Copy provenance/action serta placeholder dianggap final | Keduanya tetap provisional dan route-local sampai Human Design review menyetujuinya. | open |
