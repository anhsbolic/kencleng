## What & why

Build the Slice-1 Public Campaign Detail experience against the already-reconciled public contract while backend/topology are still being implemented. The frontend uses the real production request path and generated types; MSW intercepts only at the network boundary so mock verification exercises the same client path that later reaches the real backend.

- dynamic public Campaign route and route-local composition;

- truthful loading/success/404/503/network/media/funding/action states;

## Architecture / Plan

A Server route shell passes the campaign identity into the smallest Client query boundary. One typed API function makes the real same-origin request. MSW intercepts that request only in mock browser/test runtime; production data code has no fixture branch. Available media uses the supplied opaque `content_url` through native image loading.

**Components touched**

| Component | Purpose / change |
|---|---|
| Dynamic Campaign route | Bookmarkable public Detail surface |
| API/query boundary | One generated-type-backed real request path |
| MSW browser/node setup | Contract-faithful network interception |
| Route-local presentation | Truthful states and Evidence-Led Optimism hierarchy |
| Component/rendered verification | State, hostile text, accessibility, responsive evidence |

**Not touched / blast-radius boundary:** backend, OpenAPI/generated contract, Caddy/MinIO, broad global design system, Donation/Account.

## Interface Contract

| Concern | Contract |
|---|---|
| Detail request | `GET /api/campaigns/{campaignId}` |
| Detail shape | generated `PublicCampaignDetail` only |
| Media | consume supplied opaque same-origin `content_url` |
| 404 | safe not-found/not-public presentation without explanation |
| 503 | retryable unavailable presentation |
| Other/network failure | generic safe retryable failure |

Frontend does not parse raw Problem Details into user copy, recompute funding/progress, infer eligibility, or construct storage URLs.

## Key decisions

| Decision | Why / consequence |
|---|---|
| Small Client query boundary, not Server fetch | Keeps one browser MSW-to-real path |
| Generated types + one request helper | Avoids handwritten contract fork |
| MSW at network boundary only | Mock and real behavior share production data path |
| Native image for opaque `content_url` | Avoids creating a second frontend proxy/media path |
| No polling/automatic retries | Prevents silent refresh of consequential financial/state facts |
| No initial committed Playwright regression | MSW/RTL + rendered inspection + Human acceptance are proportionate for this non-mutating surface |
