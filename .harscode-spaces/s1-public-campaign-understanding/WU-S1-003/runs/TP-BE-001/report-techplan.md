## Apa & mengapa

Work Unit ini menambahkan kemampuan backend minimum agar pengunjung publik dapat membaca satu Campaign yang benar-benar tersimpan, beserta steward, pendanaan, provenance, media, dan next action yang factual. Hasil yang dituju adalah capability backend untuk `BACKEND_VERIFIED`, tanpa mengklaim integrasi browser, proxy, atau storage policy di luar kepemilikan Work Unit ini.

## Cakupan

**Termasuk**

- State PostgreSQL additive dan reversible untuk public steward, Campaign, funding/lifecycle, dan media minimum Slice 1.
- Read repository/service Campaign, public eligibility, closed public projection, serta perhitungan funding IDR berbasis decimal.
- Pembacaan private object MinIO dan pengiriman byte media JPEG/PNG yang terkontrol melalui dua route public yang sudah ada di kontrak.
- Command operator opt-in untuk membuat persisted seed Campaign dari manifest, termasuk media private opsional.
- Evidence unit, wire, Postgres, MinIO adapter, dan reversibilitas migration untuk perilaku yang dimiliki backend.

**Secara eksplisit tidak termasuk pada putaran ini**

- Perubahan `api/**`, Product/MVP, Campaign spec/threat model, frontend, atau generated frontend types.
- Listing, self-service Campaign/Organization, curation, upload API/UI, scheduler, closure/result, donation flow, dan perubahan Account.
- `Caddyfile`, `docker-compose.yml`, MinIO bucket policy, konfigurasi proxy/cache/header, serta bukti topology end-to-end; semuanya milik `WU-S1-005`.
- Public/signed object URL, redirect media, storage framework multi-provider, dan global public-read rate limiting.
- Perubahan area Tier-0: `backend/internal/platform/auth/**`, `backend/internal/platform/crypto/**`, donation ledger, dan disbursement state machine.

## Arsitektur / Rencana

Permintaan anonim masuk ke handler Campaign tanpa middleware autentikasi. Handler menyamakan UUID malformed dengan public not-found, lalu service melakukan lookup yang sekaligus menyaring Campaign `published` yang eligible dan membership media. Hanya data sempit yang lolos dipetakan ke public view tertutup. Untuk content media, service melakukan pengecekan parent/member per permintaan sebelum private storage reader mengalirkan JPEG/PNG; kegagalan dependency/object pada resource yang eligible menjadi `503`, bukan false `404`.

Urutan delivery: migration `000011` dan dependency decimal/integration test; domain repository/service; private MinIO reader dan composition server; handler/route public; command seed operator; lalu evidence berlapis. Seluruh respons public `200`, `404`, dan `503` menetapkan `Cache-Control: private, no-store` sebelum response ditulis.

**Komponen yang disentuh**

| Komponen | Tujuan / perubahan |
|---|---|
| PostgreSQL migration `000011` | Menyediakan state Organization, Campaign, dan campaign media yang minimal serta reversible. |
| `internal/domain/campaign` | Memisahkan public eligibility, semantic mapping, funding decimal, dan klasifikasi error dari persistence/transport. |
| `internal/platform/storage` | Menyediakan pembaca private MinIO dengan seam sempit, tanpa URL signing atau public URL. |
| HTTP transport dan `cmd/server` | Mendaftarkan dua GET public, Problem Details yang aman, header no-store, dan streaming media tervalidasi. |
| `cmd/campaign-seed` | Menyediakan setup operator yang eksplisit, tervalidasi, dan bukan workflow pengguna. |

**Tidak disentuh / batas blast radius:** kontrak OpenAPI dan frontend tidak berubah. Caddy, kebijakan private bucket, dan proxy `/api` tidak disentuh. Tidak ada perubahan pada area Tier-0 atau logika transaksi/locking balance.

## Kontrak Interface

| Perhatian | Kontrak |
|---|---|
| Endpoint | `GET /campaigns/{campaignId}` → `200 PublicCampaignDetail`, `404 PublicCampaignNotFound`, atau `503 PublicCampaignUnavailable` |
| Endpoint | `GET /campaigns/{campaignId}/media/{mediaId}/content` → `200 image/jpeg|image/png`, `404 PublicCampaignNotFound`, atau `503 PublicCampaignUnavailable` |
| Authentication / authority | `security: []`; tidak ada `RequireSession`; optional Authorization, termasuk yang malformed, tidak diparsing atau dipakai. |
| Trigger / caller | Pengunjung publik anonim. |

**Request / input**

| Field / input | Makna / requirement |
|---|---|
| `campaignId` | UUID Campaign pada path; malformed disamakan dengan public `404`. |
| `mediaId` | UUID media pada path content; harus menjadi anggota Campaign public yang eligible. |

**Response / output**

| Field / output | Makna |
|---|---|
| `PublicCampaignDetail` | Tepat sembilan top-level property: `id`, `title`, `purpose`, `story`, `steward`, `lifecycle`, `funding`, `media`, dan `donation_action`. |
| `funding` | Truth decimal: unavailable saat kedua nilai tidak ada, zero tetap factual, progress tidak dicap, dan target nol menjadi `not_computable`. |
| `media.items[].content_url` | URL same-origin opaque `/api/campaigns/{campaignId}/media/{mediaId}/content`, bukan MinIO URL atau redirect. |
| Content response | Hanya byte JPEG/PNG persisted dan tervalidasi. |

**Perilaku error:** Campaign/media yang absent, malformed, ineligible, atau non-member memakai kelas public not-found yang identik per operation. Kegagalan dependency atau object pada resource eligible adalah `503` generic. Semua respons kontrak membawa `Cache-Control: private, no-store` dan tidak membocorkan raw SQL, object key, credential, filesystem path, atau detail provider.

## Keputusan utama

| Keputusan | Alasan / konsekuensi |
|---|---|
| Tambahkan hanya state `organizations`, `campaigns`, dan `campaign_media` untuk Slice 1. | Memenuhi persisted state tanpa memperluas ke self-service, PII, atau curation. |
| Repository memakai data sempit; service memiliki public semantics; handler memiliki exact wire mapping. | Menjadikan allowlist dan klasifikasi error dapat diaudit serta mencegah field persistence bocor ke kontrak. |
| Gunakan `shopspring/decimal` untuk funding. | Menjaga ketelitian IDR dan aturan half-up tanpa `float64`. |
| Gunakan MinIO client private dengan seam Campaign yang sempit. | Produksi tetap membaca private bucket, sementara test domain tetap deterministik; tidak ada URL public/signed. |
| Gunakan testcontainers ber-tag `integration` yang terisolasi. | Evidence Campaign tidak mengubah database developer bersama; runtime/container yang tidak tersedia dilaporkan sebagai tidak terverifikasi. |
| Sediakan `cmd/campaign-seed` opt-in tanpa startup seed. | State nyata dapat disiapkan secara repeatable tanpa menciptakan surface produk baru. |
| Pisahkan evidence backend langsung dari topology. | `WU-S1-003` dapat membuktikan capability backend tanpa klaim proxy/policy/frontend yang dimiliki `WU-S1-005`. |

## Risiko / trade-off material

| Risiko / trade-off | Eksposur / mitigasi | Status |
|---|---|---|
| Field internal atau status dapat bocor pada public response. | Closed view, explicit select list, dedicated wire struct, dan negative HTTP tests. | mitigated |
| Enumerasi eksistensi melalui body, header, Authorization, atau timing. | Kelas not-found tunggal, header/body identik, auth diabaikan, serta pengukuran timing oleh Testing. | mitigated; evidence timing menunggu Testing |
| URL media yang diketahui tetap dapat dipakai setelah retraction atau object dapat diakses langsung. | Recheck parent/member tiap request, private client, tanpa redirect/no-store; policy/proxy/retraction nyata diserahkan ke `WU-S1-005`. Byte yang sudah terunduh adalah residual exposure yang diterima. | mitigated / verifikasi eksternal menunggu |
| Kegagalan object salah disajikan sebagai tidak ada media. | State metadata dipisahkan dari availability pembacaan dan eligible read failure dipetakan menjadi `503`. | mitigated |
| Pembulatan atau skala funding mengubah kebenaran nominal. | `NUMERIC(19,2)`, decimal, dan test zero/over-target/not-computable/half-up. | mitigated |
| Seed menghasilkan media invalid atau public-looking state. | Manifest dan media divalidasi, object key opaque dibuat oleh command, private bucket saja, tanpa migration seed. | mitigated |
| Penggantian seed meninggalkan private object orphan. | `--replace` harus eksplisit; cleanup pasca-commit best-effort dilaporkan dan menjadi tanggung jawab operator. | accepted |
