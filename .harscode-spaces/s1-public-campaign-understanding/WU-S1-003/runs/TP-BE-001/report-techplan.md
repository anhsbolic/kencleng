## What & why

Build the minimum real backend capability behind Slice 1's already-approved public Campaign contract: persisted public-safe Campaign/steward/funding/media state, exact public projection, controlled private-media bytes, and an operator-only seed path. The goal is to earn `BACKEND_VERIFIED` without claiming Caddy/MinIO-policy/frontend integration.

## Scope

**Included**
- additive/reversible minimum PostgreSQL state for Organization steward, Campaign, funding/lifecycle, and Campaign media;
- Campaign repository/service/public handlers for the two reconciled public reads;
- exact decimal funding semantics with no `float64`;
- private MinIO object-read seam using `MINIO_BUCKET_PRIVATE`;
- operator-only seed command for real persisted test/demo Campaign state;
- backend-owned unit/wire/Postgres/MinIO verification.

**Explicitly not included this round**
- Caddy, Docker Compose, MinIO bucket policy, or proxy/header proof;
- frontend implementation or real browser integration;
- Donation, Account, closure/accountability, listing/self-service/curation/upload breadth;
- Product/API/spec changes.

## Architecture / Plan

The backend adds a narrow Campaign domain. Repository reads explicit persisted columns; the Campaign service owns public eligibility and public semantics; transport owns exact HTTP mapping and no-store responses. Media requests re-check parent eligibility and membership before reading an opaque object from the private bucket. A separate opt-in seed command creates truthful persisted data without introducing a user-facing creation workflow.

**Components touched**

| Component | Purpose / change |
|---|---|
| PostgreSQL migrations | Minimum real Slice-1 persistence |
| Campaign domain/repository/service | Public eligibility, projection, funding/media semantics |
| MinIO storage seam | Private-object reads only; no URL signing/public URLs |
| HTTP transport/server wiring | Public detail + media routes, 404/503/no-store behavior |
| Operator seed command | Repeatable persisted Campaign setup |

**Not touched / blast-radius boundary:** OpenAPI/Product/spec/frontend/root topology/Tier-0 auth/crypto/donation/disbursement paths.

## Interface Contract

The implementation consumes the existing contract unchanged:

| Concern | Contract |
|---|---|
| Public detail | `GET /campaigns/{campaignId}` |
| Public media | `GET /campaigns/{campaignId}/media/{mediaId}/content` |
| Authentication | Public; optional Authorization must not enrich/change response |
| Browser-visible prefix | `/api` remains topology-owned by WU-S1-005 |

**Error behavior:** malformed/absent/non-public/non-member collapses to the safe public 404 class; eligible dependency/storage failure is 503; relevant 200/404/503 responses carry `Cache-Control: private, no-store`.

## Key decisions

| Decision | Why / consequence |
|---|---|
| Minimum new persistence, not historical full Campaign model | Real state without importing deferred self-service/PII breadth |
| Service-owned public semantics + exact wire mapping | Prevents persistence/internal-field leakage |
| `shopspring/decimal` for public funding computation | Preserves exact money/progress semantics |
| Private MinIO read seam only | Keeps controlled delivery revocable and testable |
| Operator seed command, not migration/startup seed | Real data without inventing product workflow |
| Isolated testcontainers integration evidence | Avoids mutating developer/shared DB and makes backend proof independently executable |
