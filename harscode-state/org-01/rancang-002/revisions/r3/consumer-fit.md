## Frontend response boundary

T06 small typed client/result boundary distinguishes HTTP success with validated expected body, HTTP RFC9457 rejection identified by `type` and `status`, transport failure, and malformed/unexpected response. Generated TypeScript is compile-time shape, not runtime validation or authorization. For consequential mutations, a malformed/partial apparent success or missing response stays unknown until supported authoritative inspection; it is not a generic “failed, try again” branch. 204/303 have no JSON body; callback is full-page browser navigation. English fixed problem title/detail is wire text, not Product copy authority: UI may provide Bahasa Indonesia explanation from stable type/context, keeping field validation associated and never parsing title as decision authority. No wire `success` flag, generic `code` or extra profile/status endpoint is required.
